# Hospital Performance Dashboard

A Power BI dashboard built to analyze hospital admissions, patient utilization, department performance, length of stay, and billing data.

## Tools Used

* Power BI
* DAX
* Excel

## Dashboard

The dashboard includes:

* Overview of key hospital metrics
* Patient and admission analysis
* Revenue and billing analysis
* Department performance comparison
* Management-focused insights

Interactive **slicers and page navigation** are included to make it easier to explore the data across different departments and categories.

## Data Preparation

The data was cleaned and prepared in Excel before being used in Power BI. This included handling duplicate records, standardizing department names, correcting date-related issues, and calculating Length of Stay (LOS).

## Purpose

The project focuses on presenting hospital data in a clear and practical format that can help identify patterns in admissions, patient stay, departmental performance, and billing.
